리뷰 피드백 #1(동일 데이터) · #2(k-fold) · #4(R²·MAE·MSE) · #6(데모 홀드아웃)을 모두 반영한 재실행 결과. 생성: [scripts/run_protocol_comparison.py](scripts/run_protocol_comparison.py), 프로토콜: [scripts/protocol.py](scripts/protocol.py)

> **수치 기준 — 이 문서 §2~§6은 A100 완주판이다.**
> 4개 백본을 전부 **2048점 · patience-200 · 동일 배치**로 완주시킨 실행이며, 루트 [README.md](../README.md)가 싣는 값과 같다.
> ML 트랙은 GPU와 무관하므로 재실행하지 않았고 값도 그대로다.
> 원본은 [`outputs/protocol_dl2048_a100.json`](outputs/protocol_dl2048_a100.json) — 아래 DL 수치는 전부 이 파일에서 옮긴 값이다.
> 5080에서 먼저 돌린 실행(2048점·patience 기본, 1024점 4백본)은 [부록 A](#부록-a--5080-실행-기록-참고)에 원문 그대로 보존했다.

## 5. 핵심 결론

1. **동일 조건에서도 DL이 압도**: PointNet **+0.878** vs 최고 ML(AutoGluon) **+0.573** → 격차 **+0.305**. MAE는 6.25 vs 11.66 counts로 **46% 낮음**.
   → "데이터가 달라서 DL이 좋아 보였다"는 가설은 기각됨. **형상 정보 자체가 파라미터보다 Cd를 훨씬 잘 설명**한다.
2. **ML은 Estate에서 붕괴**: AutoGluon +0.038, XGBoost -0.079, RandomForest **-0.257** (평균 예측만도 못함). 반면 PointNet은 세 차종이 **+0.816 / +0.823 / +0.825**로 고르다.
   → "파라미터로는 차종 내부를 설명할 수 없고 형상이 필요하다"는 주장이 공정 조건에서 재확인됨.
3. **형상 모델 안에서는 작은 쪽이 이긴다**: PointNet(0.81M) > DGCNN(1.80M) > RegDGCNN(3.16M). 파라미터 수와 역순이다. 항력은 전역 실루엣이 지배하고 국소 표면 디테일이 아니라는 뜻이며, CPU 서빙이 가능한 이유이기도 하다.
4. **안정성**: 5-fold 표준편차가 DL 0.006~0.007, ML 0.018~0.033으로 작아 fold 운에 좌우되지 않는다. 단 ML의 Estate는 편차가 ±0.142로 매우 불안정.
5. **순위 정확도 격차는 상대적으로 작음**: PointNet 89.1% vs AutoGluon 78.3%. ML도 "둘 중 어느 쪽이 저항이 낮은가"는 78% 수준으로 맞힌다. **절대값 예측(MAE)에서 격차가 훨씬 크다**.

## 6. 이전(불공정) 수치와의 관계

| | 이전 (서로 다른 데이터) | 현재 (동일 데이터) |
|---|---|---|
| PointNet | 0.968 (7,713대, 공식 split) | **0.878** (3,704대, K=5) |
| AutoGluon | 0.549 (4,165대, 80/20×20) | **0.573** (3,704대, K=5) |

PointNet이 0.968 → 0.878로 내려간 것은 **성능 저하가 아니라 조건 변화**다: 학습 데이터가 절반 이하로 줄고(7,713→3,704), 교집합이 신세대만 남아 **Cd 분산이 0.037 → 0.023으로 좁아졌다**(R²가 구조적으로 불리해짐). AutoGluon은 오히려 소폭 상승했고, 이제 두 모델이 같은 조건이므로 **격차 +0.305가 진짜 값**이다.

## 7. 지표 정의

| 지표 | 정의 | 성격 |
|---|---|---|
| **R²** | 1 − SSE/SST | 해당 부분집합 자체 평균 대비. 분산 작은 클래스에 가혹 |
| **MAE** | mean(\|ŷ−y\|) | Cd 원단위 절대오차 |
| **MSE / RMSE** | mean((ŷ−y)²) / √MSE | 큰 오차에 더 큰 벌점 |
| **MAE(counts)** | MAE × 1000 | 도메인 단위(1 count = 0.001 Cd), 차종 간 비교 가능 |
| **순위 정확도** | 무작위 두 설계 중 저항 낮은 쪽 적중률 | 제품이 실제 주장하는 기능. 50% = 동전던지기 |
| MAPE | mean(\|ŷ−y\|/y)×100 | 백분율 오차. **다음 실행부터 산출**(protocol.py에 추가됨) |

## 8. 재현

```bash
python scripts/protocol.py                    # 분할 검증
python scripts/run_protocol_comparison.py --only ml                     # ML 트랙
python scripts/run_protocol_comparison.py --only dl --npoints 2048 \
    --backbones pointnet dgcnn regdgcnn --patience 200                  # DL 트랙 (A100 조건)
```

A100 실행의 원본은 [`outputs/protocol_dl2048_a100.json`](outputs/protocol_dl2048_a100.json)에 커밋돼 있다 — 3,704대 · K=5 · 2048점, 백본 3종 × (전체 + 차종 3)의 R²·MAE·MSE·RMSE·MAE(counts)·MAPE·순위정확도가 평균과 표준편차로 들어 있다. 재실행하면 `outputs/protocol_comparison.json`이 새로 생성된다.
